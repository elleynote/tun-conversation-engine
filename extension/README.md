# Tun Conversation Engine Chrome Extension

Automates Reddit commenting directly from your authenticated browser session without needing official Reddit API credentials.

## Installation (Takes 30 seconds)

1. Open Google Chrome.
2. Navigate to: `chrome://extensions/`
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** (top-left).
5. Select this `extension` folder:
   `C:\Users\HP\.gemini\antigravity\scratch\tun-conversation-engine\extension`
6. The extension **Tun Conversation Engine Auto-Poster** is now active!

## How It Works

1. On your Tun Dashboard (`localhost:3000` or Netlify deployment), open any opportunity.
2. In the review box, click **"⚡ Auto-Post to Reddit"**.
3. The extension:
   - Opens the Reddit discussion in a tab.
   - Types your approved reply with human-like input events.
   - Clicks the submit button.
   - Automatically marks the item as **"Posted"** in your Tun dashboard.
   - Closes the Reddit tab after 3 seconds.

Zero API tokens or Reddit developer permissions required.
